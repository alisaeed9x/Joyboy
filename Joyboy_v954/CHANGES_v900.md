# v900 — الشريط السفلي العايم الزجاجي (زي صفحة الميديا) في المتصفح + الملفات + نقل الملفات
- `MtGlassView.kt` (MtFloat): `eligible(act)` (موبايل · أندرويد 12+ · مش تابلت/تلفزيون) + `build(...)` بيرجّع صفحة = محتوى + الشريط الزجاجي العايم (بلور حقيقي + عدسة التنقّل + اهتزاز)؛ `attach` بقت تستخدمه (سلوك الميديا ما اتغيّرش). `reserve=true` بيحجز مكان الشريط تحت المحتوى (للمتصفح).
- `Browser.kt` · `FileManager.kt` · `FtUi.kt`: الشريط بقى عايم زجاجي بدل الصلب لما `MtFloat.eligible`؛ التلفزيون/التابلت/أندرويد <12 زي ما هما.
- ⚠ مش متكومبايل ولا متجرّب. يوتيوب (MeeTube module) والدايلوجات/الكبسولات العايمة لسه — الدفعة الجاية.
