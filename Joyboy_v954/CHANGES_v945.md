# v945 — كبسولة العدّاد + ألوان تفعيل 🔂/💬 في شريط Joyboy جوه مشغّل MeeTube

- **كبسولة العدّاد (`MtBar.badgeCapsule` / `refreshBadge`):** زي `TransBadge` القديم — «🔊 N% · N جملة ▾» + سطر النت «🌐 · 🔗» (`NetUse.badgeLine`) + «👁 N» لما الوضع البصري شغّال. نقطة الحالة: خضرا = الترجمة شغّالة، حمرا = واقفة/متوقفة. فوق على الشمال بنفس ارتفاع الشريط (58dp لاندسكيب / 72dp بورتريت)، والشريط العلوي بقى ليه هامش شمال 170dp فبيتسحب جنبها من غير ما يغطّيها. دوسة عليها = لوج الترجمة (`showLog`).
- **ألوان التفعيل (`refreshModes`):** 🔂 أزرق لو وضع التكرار مش «عادي» (`MtMedia.loopMode() != 0`)، 💬 أزرق لو وضع الترجمة غير «فردي» (`sub_dual != 0`)، وغامق لما يكونوا مقفولين — بتتحدّث من الـtick كل 700ms وبعد كل دوسة.
- **ملف واحد معدّل:** `MtBar.kt` (مفيش `.kt` جديد ← `kt_manifest.txt` ما اتغيّرش).
- **ما اتعملش (وليه):**
  1. **شريط التقدم بين شريحة الترجمة والصف الرئيسي:** شريط MeeTube (`PlayerTimeBar` + `SeekFilmstrip`) برّه طبقة الأزرار ومربوط بسحب/فيلمستريب/فصول، ونقله من `:app` ممكن يكسرهم. ورسم شريط تاني بدله هيعمل شريطين. محتاج قرار + تجربة على الجهاز.
  2. **⬜ «اسألني عند الخروج»:** مسار MeeTube مابيقراش `ask_bg_exit` أصلًا (الخروج بيعمل `stopEngine()` في `MtTranslate.detach`)؛ الزرار لوحده هيبقى بيغيّر إعداد ما بيأثرش. محتاج ربط `askBgOnExit` (Player.kt:6432) بزرار الرجوع الأول.
  3. **كارت العنوان:** MeeTube بيرسم العنوان بتاعه، وإضافة كارت تاني هتتداخل معاه.
- **ما اتجرّبش:** مفيش Gradle هنا — البناء على GitHub Actions. تداخل الكبسولة مع هيدر MeeTube لازم يتشاف على الجهاز.
