# Continuity AI

مساحة عمل ذكاء اصطناعي (عربي RTL / English LTR) بذاكرة مشروعات، اختيار نموذج، إدارة اتصالات، تحويل تلقائي لاتصال بديل، ونقاط استئناف. تطبيق أندرويد (Capacitor) يُبنى على GitHub Actions.

## بناء الـ APK على GitHub
1. أنشئ مستودعًا جديدًا وارفع **كل** محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يعمل تلقائيًا عند أي push على `main`).
3. بعد انتهاء البناء (~5 دقائق) نزّل **ContinuityAI-APK** من قسم Artifacts، فُكّ الضغط وثبّت `app-debug.apk` على الموبايل.

## الاستخدام
`الاتصالات` ← إضافة اتصال (Anthropic / OpenAI / OpenRouter / Groq / Gemini / Ollama محلي / مخصص) ← حفظ واختبار ← اختر النماذج المسموحة ← ارجع للمحادثة.

## ما هو منفّذ فعليًا
- محادثات + بث (Streaming) + Markdown/كود + نسخ/إعادة توليد/إيقاف، وحفظ تلقائي في IndexedDB واستعادة بعد الإغلاق.
- مشروعات وذاكرة مشروع تُحقن في تعليمات النظام.
- اتصالات متعددة؛ المفاتيح مشفّرة AES-GCM بمفتاح غير قابل للتصدير داخل الجهاز، ولا تدخل في أي تصدير.
- قائمة النماذج تُجلب من المزوّد نفسه (لا أسماء مفترضة) وأنت تحدد المسموح منها.
- توجيه: يدوي / بالأولوية / الأكثر موثوقية / الأقل تكلفة (بأسعارك)، مع إظهار سبب الاختيار.
- Auto-Fallback: تصنيف الأخطاء (401/403/429/5xx/شبكة)، احترام Retry-After، تحويل مُعلن (غير صامت)، ومتابعة الرد الجزئي بالاتصال البديل، وحد ميزانية لكل اتصال.
- الاستخدام: حدود المزوّد وموعد Reset تظهر **فقط** إن أعادها المزوّد في الترويسات وكانت مكشوفة للمتصفح (مؤكد من المزوّد)، وإلا «غير متاح من المزوّد». العدّادات المحلية مُعلّمة «محسوب محليًا». العد التنازلي محلي ولا يعلن عودة الحصة بعد الموعد قبل تحديث الحالة.
- **دواير الحالة (1،2،3…) أعلى الشاشة:** 🟢 شغّال، 🔴 الليميت خلصان (429 أو تجاوز الميزانية)، 🟠 خطأ آخر (مصادقة/شبكة/خادم)، ⚪ لم يُختبر. الدايرة بحلقة = الاتصال المستخدم في المحادثة. الضغط على دايرة يفتح تفاصيلها واختبارها وزر «استخدمه». زر ↻ يختبر الكل بطلب حقيقي صغير (يُرسل `ping` بـ 8 توكن). الاختبار تلقائي عند فتح التطبيق وعند انتهاء مهلة الانتظار.
- **النقل بين الاتصالات:** عند فشل اتصال تتنقل المحادثة كاملة (كل الرسائل + آخر Checkpoint + الرد الجزئي) للاتصال التالي، ويبقى الاتصال الجديد هو الحالي في المحادثة.
- **صفحة «السجل»:** كل طلب ورد (Request/Response) في صفحة واحدة قابلة للطي مع زر نسخ الكل. المفاتيح لا تُسجَّل.
- Checkpoints + استكمال المهمة + تصدير/استيراد حزمة السياق (JSON بدون أسرار) + تصدير المحادثة Markdown/JSON.
- **المرفقات (📎):** صور (تُصغَّر لـ1600px وتُرسل كرؤية)، PDF (حتى 10MB)، ملفات نصية/كود (حتى 500KB)، وفيديو (يُستخرج منه 8 لقطات موزعة + مدته وتُرسل كصور، لأن واجهات المحادثة لا تقبل ملف فيديو). المرفقات تُحفظ على الجهاز منفصلة عن المحادثة، ويُرسَل آخر 6 رسائل فيها مرفقات فقط عند كل طلب. يتطلب نموذجًا يدعم الصور/PDF.
- **التفريغ الصوتي (🎤):** اضغط للتسجيل واضغط مرة ثانية للإيقاف، فيُفرَّغ الكلام إلى صندوق الكتابة لتراجعه قبل الإرسال. كما يمكن رفع ملف صوتي ليتفرّغ. يعمل عبر اتصال متوافق مع OpenAI: `/audio/transcriptions` (OpenAI/Groq) أو `chat + input_audio` (Gemini)، ويمكن ضبط الاتصال والنموذج من الإعدادات، ويجرّب الاتصال التالي لو فشل. Anthropic لا يدعم الصوت.

## غير منفّذ في نسخة الأندرويد
بوابة API المحلية، مساحة عمل ملفات/Git، تشغيل أوامر، صور مرفقة، وضع Best Fit، وقاعدة SQLite/خادم Node (التخزين محلي على الجهاز).

## قيود مهمة
- التطبيق يتصل بالمزوّد مباشرة من الجهاز، فيجب أن يسمح المزوّد بـ CORS (Anthropic عبر ترويسة المتصفح المباشر، وOpenAI/OpenRouter/Groq/Gemini/Ollama عادةً يسمحون).
- الـ APK الناتج Debug (يُثبَّت مباشرة). للنشر على المتجر أضف توقيع Release.
- لم يُختبر على مزوّدين حقيقيين بمفاتيح فعلية؛ الاختبار الآلي استخدم مزوّدًا وهميًا (بث، 429 ثم تحويل، التشفير).
