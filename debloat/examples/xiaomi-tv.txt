# Bloat removed from a Xiaomi OLED TV (Android TV 11, MediaTek). 32 packages.
# Hidden with `pm uninstall -k --user 0`, so every one can be restored with restore.sh.
# Other Xiaomi TVs ship a similar set; check `adb shell pm list packages` before using this as-is.
#
# NEVER remove on a TV: Live TV (com.mitv.livetv), anything com.mediatek.*, mitv.service, the remote's
# Bluetooth service (com.mi.bluetooth), picture/sound settings (com.android.tv.settings), Play Services,
# the keyboard, the setup wizards. Doing so can break the remote, the inputs or booting.
