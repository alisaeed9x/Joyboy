# AUDIT_MANUAL_QA — قوائم اختبار يدوي (لم تُنفَّذ)
كل البنود **غير منفّذة**؛ هي خطوات للتحقق على أجهزة حقيقية بعد البناء.

## موبايل
- [ ] ui_mode=auto على هاتف: يفتح MainActivity بواجهة الموبايل؛ تدوير الشاشة لا يعيد بناء/يكسر.
- [ ] ui_mode=tv على هاتف: يُقفل لاندسكيب (`forcesLandscape`)، Back يرجع للتلفزيون؛ ui_mode=phone يرجع الوضع الطبيعي.
- [ ] Back من تبويب يوتيوب/إعدادات يرجع للتبويب الصحيح؛ لا حلقة بين Main وTvActivity.
- [ ] مشاركة رابط يوتيوب / نص بلا رابط إلى التطبيق؛ مسح QR `subtitler://ytlink`.
- [ ] اضغط Home واختر الشاشة الرئيسية: هل يظهر Subtitler كخيار؟ (D-03)
## تابلت
- [ ] auto على تابلت (≥600dp): يُعامَل كتابلت؛ تحقق من مؤشر المتصفح/مفاتيح المشغّل (يعمل كريموت — D-04).
## Android TV
- [ ] أيقونة التطبيق → TvActivity. بلاطة يوتيوب → يوتيوب داخل Main (شريط اللانشر)، Back → اللانشر.
- [ ] أول تشغيل يوتيوب: هل تظهر حوارات صلاحيات/«إيه الجديد»؟ (D-01)
- [ ] Back داخل يوتيوب: التراجع داخلياً ثم اللانشر دون خروج من التطبيق.
- [ ] تطبيق غير مثبّت كاختصار: رسالة «التطبيق مش متاح».
## ريموت
- [ ] لا يضيع التركيز بعد غلق حوار؛ لا قفز للعنصر الأول.
- [ ] Menu في اللانشر/Main/Browser/Player؛ 0 مطولاً 5ث (أيقونة إلغاء التثبيت) ثم إلغاء من النظام.
- [ ] تفعيل خدمة الـAccessibility: تأكد أن أزرار ريموت التلفزيون الفعلي تعمل طبيعياً داخل تطبيق يوتيوب الرسمي/Subtitler (R-01).
## متصفح
- [ ] وضع المؤشر/التركيز، Menu، Back (history ثم إغلاق التبويب ثم خروج)، رابط خارجي intent:// (يُمنع)، كتابة 0 في حقل ويب (H-02).
## تشغيل ميديا
- [ ] مشغّل: ←/→ تقديم 10/30/60، OK يظهر الشريط، أرقام، صوت، حلقة جاية، رجوع لنفس الشاشة (`ret`).
- [ ] خلفية/أمام، إعادة إنشاء Activity، فتح/غلق حوارات متكرر (ذاكرة/تجمد).
