# v4.84 — الشاشة الرئيسية للانشر بترتيبك

الترتيب من فوق لتحت (`TvHome.kt`):
1. **الشريط العلوي:** الأزرار الخمسة + الساعة. الساعة بقت **12 ساعة (ص/م)** بتوقيت الجهاز.
2. **📲 دواير التطبيقات:** تطبيقات الجهاز الأساسية بس (من غير الإعدادات/الإعداد الأول/مثبّت الحزم… وأمثالها). اللي عليه الريموت بيكبر (×1.38) وإسمه تحته بيتلوّن؛ الباقي أصغر. OK = فتح، دوسة طويلة = معلومات التطبيق (مسح/إيقاف). ملحوظة: تطبيقات السيستم اللي اتحدّثت (زي YouTube TV) بتظهر عادي.
3. **🕘 آخر الفيديوهات المشغّلة:** السجل، الأحدث أول واحد، والسهم بيمشي للأقدم فالأقدم. مصغّرة + اسم + شريط تقدّم. دوسة طويلة = مفضلة.
4. **🎬 الفيديوهات:** فولدرات، كل فولدر صف فيديوهات (أول 30 + «كل الـN»). زرار **⋮ ترتيب**: ترتيب الفولدرات (الاسم/الأحدث/الأقدم/الحجم) وترتيب الفيديوهات جوه (الاسم A→Z افتراضي/الأحدث/الأقدم/الحجم). بيتحفظ.
5. **▶ أحدث اشتراكاتك على يوتيوب:** بتظهر بس لو مسجّل دخول (من الكاش، وتتحدّث في الخلفية). OK = تفتح صفحة الفيديو في يوتيوب البرنامج.
6. **🎛 تخصيص:** إظهار/إخفاء كل قسم + «إظهار تطبيقات السيستم كمان».

اتشال من الرئيسية: البانر الكبير، وصول سريع، المفضلة، «أحدث الفيديوهات» (الريل الجانبي زي ما هو).
