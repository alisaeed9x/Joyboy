# v5.04 — توهّج ثابت وسكرول ثابت
- التوهّج: اتشال تحريكه مع التركيز؛ الخلفية ثابتة (اللون الابتدائي) ومبقاش في إعادة رسم مع كل حركة.
- السكرول: مبقاش بيتحرك مع كل ضغطة. بيتحرك بس لو الصف اللي عليه التركيز خرج (كله أو جزء) من المنطقة الظاهرة، وساعتها بيحط الصف تحت الشريط العلوي. على الشاشة الواسعة الصعود للشريط العلوي بيرجّع لفوق؛ مع القايمة الجنبية مفيش رجوع تلقائي.
- ملف: TvHome.kt. ما اتكومبايلش ولا اتجرّب.
