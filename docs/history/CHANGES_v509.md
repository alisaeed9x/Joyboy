# v5.09 — مرحلة 1: ريموت مشغّل الفيديو (وضع التلفزيون)
- السبب: عدّاد الترجمة (وباقي الأزرار العايمة الدايمة) كان بياخد التركيز، فـ tvOverlayFocused() يعتبره «لوحة مفتوحة» ويسيب OK والأسهم تروح له بدل المشغّل.
- الحل: tvSnapChrome()/tvIsChrome() — الأزرار الدايمة فوق الفيديو مش بتتحسب لوحة مفتوحة، فيمين/شمال = تقديم/ترجيع، وOK = يظهر شريط التحكم.
- OK بقت تظهر الشريط بس (التشغيل/الإيقاف من زرار ▶ جواه).
- مفاتيح الصوت (↑/↓/كتم) بقت معالجة صراحةً: صوت النظام، ولو التلفزيون صوته ثابت → صوت المشغّل نفسه.
