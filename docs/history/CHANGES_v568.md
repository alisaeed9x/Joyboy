# v568 — إصلاحات وضع التلفزيون (ماعملتش compile ولا جهاز؛ اتفحص توازن الأقواس بس)

## 1) الفيديو كان بيقف على التلفزيون لما تخرج من شاشة التحكم
السبب: الخروج (رجوع / إشعار / PiP / فتح الإعدادات) كان بينادي `player.pause()` وفي وضع المتحكم دي بتبعت أمر إيقاف للتلفزيون.
الإصلاح (Player.kt): `leaveController()` + حراسة `remote` في onBackPressed / closeNoBg / closeAfterPip / exitAll / fullStop / openSettings / translateInBackground. القفل بقى من كبسولة ✕ بس.

## 2) يوتيوب بيفتح في المتصفح عند إعادة التشغيل من «آخر المشغّلة»
السبب: كان بيفتح لينك الستريم المحفوظ كصفحة ويب. دلوقتي: `Recents.ytIdOf` → يوتيوب بالمعرّف في قسم يوتيوب (وفي وضع التلفزيون يتبعت للتلفزيون)، وأي لينك تاني كفيديو (how=video). Main.reopenRecentLink + TvHome.playRecent.

## 3) إعدادات الموبايل ماكانتش بتتطبّق على التلفزيون
- `TvSync` (PlayTarget.kt): مزامنة عامة من أي شاشة طول ما وضع التلفزيون شغّال + لقطة إعدادات العرض (sub_* / fit / fs_fit / loop / autoplay_wrap) قبل فتح أي فيديو.
- BrainRpc: + fit, fs_fit, autoplay_wrap في القايمة البيضاء؛ conf.reload بيطبّق الملاءمة.
- الصوت: زراير صوت الموبايل + السلايدر + سحب الصوت = صوت التلفزيون (op جديد `volume.set`، والحالة فيها `vol`).
