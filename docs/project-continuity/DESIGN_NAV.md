# DESIGN_NAV — التنقل والتركيز والرجوع (المرحلة 1)
## 1) الشاشات
الرئيسية ← {المكتبة/المجلدات ← قائمة فيديو ← المشغّل} · السجل · البحث · YouTube(خارجي) · التطبيقات · الإعدادات ← {ثيمات · فهرسة · سكون · صفوف}. فوقهم طبقتان: **حوار** (PIN/تأكيد/قائمة) و**شاشة السكون**.
تخطيط الرئيسية: شريط علوي (اسم + بحث + ساعة) + ريل جانبي (RTL، يمين) + صفوف أفقية (متابعة · مفضلة · أحدث).

## 2) التركيز
- أول دخول: التركيز على أول عنصر في «متابعة المشاهدة» (أو أول ريل لو فاضي).
- أسهم: داخل الصف يمين/شمال، بين الصفوف فوق/تحت، من أول عنصر يسار→الريل. تكبير 1.05 + إطار ثيم على المحدد.
- **العودة من أي شاشة فرعية ترجّع التركيز لنفس العنصر اللي فتحها** (يتسجّل `lastFocusedKey` لكل شاشة).

## 3) مكدّس الرجوع (هو جوهر FR-NAV-1) — خطوة واحدة لكل ضغطة
ترتيب ثابت، أول طبقة تستهلك الضغطة:
1. **شاشة السكون** ظاهرة ← تصحى فقط (لا خروج).
2. **حوار/قائمة منبثقة** ← تتقفل (أو خطوة داخلها لو فيها خطوات).
3. **تحديد/بحث نشط** (مثلاً نص مكتوب) ← يمسح.
4. **شاشة فرعية** (بحث/قائمة فيديو/إعدادات/تطبيقات) ← ترجع للي قبلها مع استعادة التركيز.
5. **المشغّل** ← يحفظ الموضع ثم يرجع للشاشة اللي فتحته (ما يخرجش للرئيسية لو جاي من مجلد).
6. **الرئيسية** ← لا شيء يخرج المستخدم من الـ Launcher (الـ Launcher ما بيقفلش بـ Back؛ يتجاهل أو يرجّع التركيز لأول عنصر).
القاعدة: لا Activity تعتمد على `setOnKeyListener` للرجوع. التنفيذ: واجهة `BackHandler { onBack(): Boolean }` + `OnBackInvokedCallback` على API 33+ مع `onBackPressed` fallback (D-002). الـ Launcher نفسه لا يطلع بـ finish() من الرئيسية.
الخبرة المنقولة من v476: (أ) السكون يصحّى بدون خروج، (ب) البحث بيرجع للرئيسية مش للخروج، (ج) سويب/Back داخل WebView يمر على `onBackPressed`.

## 4) الحالات الخاصة
- **لا صلاحيات:** بطاقة واضحة «محتاج إذن الفيديو» + زر منح، والبقية تعمل.
- **لا فيديوهات:** رسالة + «أعد الفحص».
- **تحميل:** مؤشر تقدم، لا تجميد للواجهة.
- **خطأ فتح YouTube/تطبيق:** إشعار صغير، يرجع للرئيسية بنفس التركيز.
- **ملف محذوف/منقول من السجل:** يظهر معلّمًا «غير موجود» مع خيار الحذف، ولا يُحسب مكتمل.
- **السجل vs قائمة التشغيل:** «التالي/السابق» من الريموت داخل المشغّل = قائمة التشغيل الحالية فقط؛ السجل ما يتحرّكش بيه.
