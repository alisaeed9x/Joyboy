## 2) ازاي تبني وتختبر
1. ارفع الريبو على GitHub → Actions: job `build` (APK debug) + job `jvm-tests` (اختبارات المنطق). **ابعت اللوج لو فشل** وأصلح الكود (مش الاختبار إلا لو غلط).
2. على جهاز/محاكي: `sh dev-tests/adb_smoke.sh <apk>` ثم جدول B في `TEST_PLAN_FINAL.md` على TCL.
3. أول أخطاء متوقعة: تواقيع NewPipe (`YtNp.kt`) وتواقيع media3 (`PlayerLayer.kt`: `MergingMediaSource`، `setMediaSource(src, pos)`، `onCues`، `setPreferredTextLanguage`)، ومحتمل `jitpack`/desugaring في Gradle.
