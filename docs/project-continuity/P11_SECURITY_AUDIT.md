## اتراجع وسليم (بالقراءة)
- صلاحيات: `READ_MEDIA_VIDEO` (+`READ_EXTERNAL_STORAGE` حتى API 32) و`INTERNET` بس. لا MANAGE_EXTERNAL_STORAGE / RECORD_AUDIO / QUERY_ALL_PACKAGES. التطبيقات بـ `<queries>` leanback.
- أسرار: grep ما لقاش مفاتيح/توكنز/كلمات مرور/keystore في الكود؛ `.gitignore` بيستثني jks/keystore/apk/local.properties.
- شبكة: الصور https فقط؛ يوتيوب بدون كوكيز/حساب (D-013)؛ مفيش تتبّع/تحليلات؛ مفيش http:// في الكود.
- مكوّنات: `HomeActivity` هي الوحيدة المصدَّرة (لازم Launcher).
- المكتبة المحلية مستقلة عن النت: يوتيوب كله في خيوط/طبقة منفصلة، وفشله بيعرض رسالة + إعادة.
- الكتابة: السجل ذرّي بخيط خلفي؛ الفحص `catch Throwable` + `gen` بيلغي القديم؛ كاش تالف ← قايمة فاضية مش كراش.
- توافق: `OnBackInvokedDispatcher` ≥33 فقط، `loadThumbnail` ≥29 فقط، desugaring لـ NewPipe — **بالقراءة، مش بتشغيل على إصدارات مختلفة**.

## اتصلّح في الجولة التانية (v0.5.2) — مكتوب بس، غير مُجمَّع
1. **كيبورد البحث بيتقفل بعد الفحص:** `onLibUpdate` دلوقتي: لو التركيز على خانة البحث ← يعيد رسم النتايج بس؛ لو على نتيجة ← إعادة بناء بنفس التركيز؛ شاشة يوتيوب ← لا إعادة رسم.
2. **نتايج الخيوط بعد onDestroy:** علم `destroyed` في الـ Activity (بحث/المزيد/تحديث المكتبة) وعلم `released` في المشغّل (جلب يوتيوب) — بيتجاهلوا أي نتيجة متأخرة.
3. **انتهاء رابط ستريم يوتيوب:** لو حصل خطأ تشغيل وكان الفيديو اشتغل قبل كده ← بنجيب رابط جديد ونكمّل من نفس الموضع (`startYt(..., resumeMs)`)، أقصى مرتين لكل تشغيل، بعدها رسالة الفشل المعتادة.
4. **فشل كتابة السجل بصمت:** `HistoryStore.writeFailed` + تنبيه مرة واحدة عند قفل المشغّل («التخزين ممتلئ أو غير متاح؟»).
