# RELEASE (P13) — مرشّح إصدار v0.5.2 (versionCode 7)
**الحالة الحقيقية:** مفيش APK اتبنى ولا اتجرّب لحد دلوقتي. المرشّح = سورس + workflow بيبني **debug APK** على GitHub Actions. ما ينفعش يتقال «إصدار جاهز» قبل نجاح A1–A3 في TEST_PLAN_FINAL.

## نوع البناء والتوقيع
- **المتاح دلوقتي:** `assembleDebug` (موقّع بمفتاح debug التلقائي بتاع Android، مش مفتاح إنتاج). كافي للتثبيت الجانبي (sideload).
- **release موقّع:** **ما اتعملش** — ما ننشئش ولا نستخدم مفاتيح من غير إذنك (أثره: التطبيق المتوقّع بمفتاح مختلف **ما يتحدّثش فوق** القديم، لازم إلغاء تثبيت = ضياع السجل لأن `allowBackup=false`). لو عايز release: ابعتلي قرارك + اعمل keystore بنفسك وحطه كـ GitHub Secrets (`VTL_KEYSTORE_B64`, `VTL_KEYSTORE_PASS`, `VTL_KEY_ALIAS`, `VTL_KEY_PASS`) — **ما تحطش المفتاح في الريبو** (`.gitignore` بيستثني jks/keystore). R8/minify **مقفول عمدًا** (NewPipeExtractor محتاج قواعد proguard ومحتاج بناء نجرّبه).
- **Google Play:** مش مناسب: تكامل يوتيوب غير رسمي (D-013) على الأغلب مخالف لسياسات يوتيوب/Play → **توزيع جانبي فقط**. لو اتوزّع عبر Play يتشال YtNp.

## متطلبات التثبيت
Android 8.0+ (minSdk 26)، تلفزيون Android/Google TV. تثبيت: `adb connect <ip>` ثم `adb install -r vanilla-tv-debug.apk`، أو تطبيق sideload على التلفزيون مع تفعيل «مصادر غير معروفة». **افتراض غير متحقق:** إن TCL يسمح بتثبيت/اختيار Launcher بديل؛ لو لا، التطبيق بيظهر في قايمة التطبيقات (LEANBACK_LAUNCHER) ويتفتح يدويًا.

## الصلاحيات
`READ_MEDIA_VIDEO` (API 33+) / `READ_EXTERNAL_STORAGE` (≤32) لقراءة الفيديوهات · `INTERNET` ليوتيوب فقط. لا ميكروفون (🎤 عبر خدمة الجهاز) ولا تخزين كامل ولا قايمة تطبيقات كاملة (بـ `<queries>` leanback فقط).

## التحديث والرجوع لإصدار أقدم
- **التحديث:** نفس `applicationId` (حاليًا `com.vanilla.tvlauncher` — **مؤقت D-005، قرر الاسم النهائي قبل أول توزيع**) + نفس التوقيع + `versionCode` أعلى. تغيير appId = تطبيق تاني (بيانات من الصفر).
- **الرجوع:** `adb install -r -d <apk-قديم>` بيسمح بالتنزيل غالبًا لبناء debug فقط؛ غير كده الغي التثبيت أولًا (`adb uninstall com.vanilla.tvlauncher`) وده بيمسح السجل والإعدادات. احتفظ بنسخ الـ APK القديمة.

## تعليمات استخدام مختصرة
الرئيسية: متابعة المشاهدة، الفيديوهات، وأكتر. الريل (يمين): الفيديوهات، السجل، البحث، يوتيوب، (التطبيقات لو فعّلتها)، الإعدادات. Back = خطوة واحدة دايمًا. الإعدادات: ثيم/حركة/خط/صفوف/مكتبة/بحث/يوتيوب/أصوات/سكون.

## المشكلات المعروفة
انظر PROJECT_STATE (غير متحقق) وP11_SECURITY_AUDIT (المفتوح) وHANDOFF_REPORT (متطلبات غير منفّذة). أهمها: الكود غير مُجمَّع، يوتيوب غير رسمي، لا ترجمة خارجية (.srt).
